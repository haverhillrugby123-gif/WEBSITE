# UK Online Tuition — Agent Contract

## Mission
Maintain and improve the GitHub Pages version of UK Online Tuition in this repository. The public Pages build is a preview/alternative frontend; the Wix production site remains separate and must not be modified from this repository.

## Safeguards
- Do not change the Wix production site or its domain from GitHub work.
- Keep canonical URLs pointing at `https://www.ukonlinetuition.co.uk/`.
- Keep `noindex,nofollow` and `robots.txt` blocking this GitHub Pages duplicate unless Dan explicitly approves an indexing/domain cutover.
- Do not add tracking, analytics, cookies, form backends, credentials or third-party scripts without explicit approval.
- Enquiries may use the client-side email handoff only; the site must not store visitor details.
- Preserve navy `#10213B`, blue `#2556E8`, cream `#F7F3EA`, paper `#FCFBF8`.

## Working method
1. Read only the files needed for the task.
2. For a broad release challenge, use the Agency roster by domain; unrelated specialist families return NOT_APPLICABLE rather than inventing work.
3. Fix shared/root causes before page-by-page patches.
4. Prefer small high-impact changes over redesigns.
5. Run `npm run check` and `npm run build` through GitHub Actions before closing.
6. Keep claims factual and avoid invented testimonials, outcomes, prices or availability.

## High-value specialist routes
- Design/UX/brand → clarity, hierarchy, responsive finish, trust.
- Frontend/code review/508 → semantics, resilience, performance, accessibility.
- Product/sales/conversion → enquiry journey and friction.
- SEO/AEO → metadata, structured data, internal linking, duplicate-site controls.
- Security/privacy → data minimisation, scripts, third-party dependencies.
- QA/project management → release gates and regression prevention.
