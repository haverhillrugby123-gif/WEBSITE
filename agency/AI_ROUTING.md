# AI Routing

Use Agency roles as an expert library rather than a meeting.

- Simple code/content fix: implement directly + CI verification.
- Important site change: Frontend/UX implementation + independent QA/accessibility review.
- Conversion change: Product/Sales + Security/Privacy where personal data is involved.
- Metadata/search change: SEO/AEO + content/claim verification.
- Full-roster sweep: only when explicitly requested; cover every relevant domain and mark unrelated families NOT_APPLICABLE.

Stop when the material defects are fixed and verified. Do not generate extra work merely to increase agent count.
